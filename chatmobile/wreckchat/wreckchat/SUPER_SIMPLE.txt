# 🎯 SIMPLEST POSSIBLE INSTRUCTIONS

## Your question: "how can i do that" (run dotnet workload restore)

---

## ⚡ THE ANSWER IN 5 STEPS

### STEP 1️⃣
Press **Windows Key** ⊞ (bottom-left of keyboard)

### STEP 2️⃣  
Type: `PowerShell`

You'll see it in the search results

### STEP 3️⃣
Right-click on **"Windows PowerShell"**

Select: **"Run as administrator"**

### STEP 4️⃣
A window opens. Copy this and paste into it:

```
dotnet workload restore
```

Press **ENTER** ↵

### STEP 5️⃣
**Wait 5-15 minutes**

You'll see progress like:
```
Installing workload: android
████░░░░░░░░░░ 25%

Installing workload: ios
████████░░░░░░ 50%
```

---

You'll see:
```

```

## ❌ IF SOMETHING GOES WRONG

### "PowerShell says Access Denied"
→ Close it. Right-click PowerShell again. Click "Run as administrator"

### "It says dotnet: command not found"
→ .NET not installed. Download from: dotnet.microsoft.com/download/dotnet/10.0

### "Installation is stuck (nothing happens)"
→ This is OK. Wait 15-20 minutes. It's downloading files.

### "Still has errors after build"
→ The workload didn't install. Run `dotnet workload clean`
→ Then run `dotnet workload restore` again
